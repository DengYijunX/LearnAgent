## 🧠 Flask 是什么？一句话解释

> **Flask** 是一个轻量级的 Python Web 框架，它让你可以用 Python 快速搭建网站或 API 接口，就像用"积木"一样灵活——想加 什么功能就加什么功能，没有多余的束缚。

---

## 📦 4 个核心概念

| 概念 | 一句话解释 | 类比 |
|------|-----------|------|
| **1. 路由 (Route)** | 决定用户访问某个 URL 时，服务器该执行什么代码 | 📍 餐厅菜单：点了"鱼香肉丝"（URL），后厨就做这道菜（函数） |
| **2. 视图函数 (View)** | 处理请求并返回内容的 Python 函数 | 👨‍🍳 厨师：收到菜单后开始做菜并端出来 |
| **3. 模板 (Template)** | 用 Jinja2 引擎渲染的 HTML 文件，可嵌入动态数据 | 📄 填空试卷：把 {{name}} 填上具体内容 | 
| **4. 请求/响应 (Request/Response)** | Flask 帮你封装好的 HTTP 请求数据和响应工具 | 📬 请求=来信，响应=回信 |

## 🖥️ 分步运行指南

### 第一步：确保安装了 Python
打开终端（Windows 用 CMD / PowerShell，Mac 用终端），输入：

```bash
python --version
```

如果看到 `Python 3.7+` 就 OK。没有的话去 python.org 下载安装。

---

### 第二步：安装 Flask

```bash
pip install flask
```

> 如果提示 `pip` 找不到，试试 `pip3 install flask`

---

### 第三步：创建程序文件

在你喜欢的文件夹里，新建一个文件，命名为 **`hello_flask.py`**

把下面的代码复制进去：

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def hello():
    return "<h1>Hello, Flask! 🚀</h1>"

@app.route("/user/<name>")
def greet_user(name):
    return f"<h1>你好, {name}! 欢迎来到 Flask 🎉</h1>"

if __name__ == "__main__":
    app.run(debug=True)
```

---

### 第四步：运行！

在终端中，**cd 到该文件所在的文件夹**，然后运行：

```bash
python hello_flask.py
```

你会看到类似这样的输出：

```
 * Serving Flask app 'hello_flask'
 * Running on http://127.0.0.1:5000
 * Restarting with stat
```

# 问题分析

## 🔴 严重 bug：_summarize_result 返回类型不一致

**现象：** 大量 "too many values to unpack (expected 2)" 错误（8+ 次）

**根因：** agent_loop.py 的 _summarize_result 函数签名声明返回 tuple[str, dict]，
但只有 search_web 分支实际返回 tuple。其余 7 个工具分支（read_url、file_write、
run_code 等）全部返回了普通字符串。调用方 summary, extra = _summarize_result(...)
尝试解包字符串时触发此错误。

**连锁影响：**
- file_write 实际写入成功了，但 on_event 回调崩溃
- LLM 收到事件异常后误判"当前环境无法写文件"
- 导致 LLM 生成了手把手文字教程，而非真正运行代码
- **实践环节完全丢失**

**修复：** 所有 return 语句补全为 tuple 格式 (summary_string, extra_dict)

---

## 🟡 403 Forbidden 问题

**现象：** ReadUrl 访问 flask.palletsprojects.com 返回 403

**根因：** User-Agent 为 "LearnAgent/0.1" 被反爬策略拦截

**修复：** 改为完整浏览器标识
