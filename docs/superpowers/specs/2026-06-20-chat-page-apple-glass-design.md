# LearnAgent 会话页 Apple 毛玻璃改版设计

## 目标

将当前可运行的 LearnAgent 会话页改造成桌面优先、接近 macOS 原生应用质感的双栏界面。改版聚焦真实存在的会话、消息、工具调用、权限确认和连接状态，不为尚未实现的产品能力搭建空页面或虚构数据。

## 范围

本轮只改造会话页及其直接依赖的公共视觉样式：

- 应用外壳与环境背景
- 会话侧栏
- 会话顶栏
- 空状态与消息列表
- 用户和助手消息
- 工具调用卡片
- 消息输入区
- 权限确认弹窗

总览、知识库、GitHub 分析、工作区、进度复盘等页面不在本轮范围内。未来页面必须根据项目中已有或新增的真实后端能力单独设计。

## 产品原则

1. 真实能力优先：界面只展示当前 store、API 和 WebSocket 已提供的数据。
2. 阅读优先：毛玻璃用于建立空间层级，不降低正文对比度。
3. 克制优先：减少装饰性卡片、无意义渐变和持续动画。
4. 上下文连续：工具执行、思考状态和权限请求都与当前会话保持关联。
5. 桌面优先：重点适配 1280px、1440px 和 1920px 宽度。

## 信息架构

页面采用双栏结构：

- 左侧固定约 260px，包含品牌标识、新建会话按钮和按更新时间排序的会话列表。
- 右侧占据剩余空间，纵向分为顶栏、消息区和底部输入区。
- 消息正文限制在约 860px 的阅读宽度内，并在大屏中居中。
- 不设置固定右侧信息栏。模式、连接、轮次和工具统计在顶栏内以低干扰方式呈现。

## 视觉系统

### 色彩

- 页面以冷白灰为底，并使用极淡的蓝、青环境光建立空间感。
- 主交互色使用清澈、低紫度的 Apple Blue。
- 成功、警告和错误色只用于真实状态反馈。
- 正文使用深灰蓝，不使用低对比度浅灰承载重要信息。

### 材质

- 侧栏、顶栏和输入区使用半透明白、细边框和 `backdrop-filter`。
- 助手正文使用接近不透明的白色表面，保证 Markdown 与代码的可读性。
- 阴影保持柔和、低扩散，不模拟厚重悬浮卡片。

### 圆角与间距

- 应用主层级使用约 24px 圆角。
- 内容卡片使用 16–18px 圆角。
- 按钮和小控件使用 10–14px 圆角。
- 通过留白和对齐建立层级，避免依赖大量边框分割。

### 字体与图标

- 字体优先使用 SF Pro、苹方及系统无衬线字体，以保持中文桌面应用质感。
- 图标统一使用项目已安装的 Lucide Vue。
- 工具卡和权限弹窗中的 emoji 全部替换为语义明确的矢量图标。

### 动效

- 消息出现、状态变化和展开收起使用 150–240ms 的轻量过渡。
- 运行中状态可使用克制的呼吸或点状动画。
- 禁止造成布局跳动的 hover 缩放。
- 通过 `prefers-reduced-motion` 为减少动态效果的用户关闭非必要动画。

## 组件设计

### 应用外壳

外壳提供冷白渐变环境背景和极淡光斑。页面保持全高，但视觉上避免大片纯色分区。当前 `ChatPanel` 残留的深色背景必须移除。

### 会话侧栏

- 品牌区简洁展示 LearnAgent 标识。
- 新建会话作为侧栏唯一主操作。
- 会话项展示主题或首条消息、消息数和相对时间。
- 当前会话通过轻玻璃底、细描边和微阴影识别。
- 学习类意图使用小型语义标签，避免抢夺标题注意力。
- 空列表提供简洁说明，不展示无效导航入口。

### 会话顶栏

- 左侧展示当前主题；无主题时显示 LearnAgent。
- 展示探索/完整模式，并允许原地切换。
- 处理中展示当前轮次与最大轮次。
- 连接状态通过图标、文字或可访问标签表达，不能只依赖颜色。
- 已完成后的工具统计以紧凑摘要显示，避免形成固定仪表盘。

### 空状态

- 使用明确的欢迎语解释 LearnAgent 的核心价值。
- 提供三个基于真实会话能力的示例问题。
- 点击示例只填入输入框，不自动发送。
- 空状态与已有消息状态共享同一消息阅读宽度。

### 消息

- 助手消息弱化传统气泡，更接近干净文档表面，适合长 Markdown、列表和代码。
- 用户消息使用浅蓝玻璃气泡并右对齐。
- 时间信息降低视觉权重，但保持可读。
- Markdown 标题、链接、行内代码、代码块和复制按钮遵循统一浅色主题。

### 工具调用

- 工具调用作为消息流内的紧凑执行条或时间线节点。
- 状态包括运行中、成功和失败，并由图标、文案和颜色共同表达。
- 运行中不可展开；完成或失败后可展开摘要、搜索结果、输入参数和耗时。
- 参数区域使用浅色等宽代码表面，不再使用当前深色卡片。

### 输入区

- 输入区悬浮于消息区底部，并保持与消息正文相同的最大宽度。
- 文本框支持自动增高，最大高度约 160px。
- Enter 发送，Shift+Enter 换行的行为保持不变。
- 发送、停止、禁用、连接缺失和处理中状态均有清晰反馈。
- 空状态示例通过明确接口向输入框写入草稿。

### 权限确认

- 弹窗使用浅色玻璃面板与柔和遮罩。
- 展示工具名称、请求原因、关键参数和可选内容预览。
- 危险操作使用适度风险色，拒绝与允许按钮层级清晰。
- 当前“同类操作 60 秒内免确认”只有日志输出，没有实际行为，本轮删除该选项，避免虚假承诺。

## 数据与状态

本轮不修改后端协议，继续使用现有数据：

- `session` store：会话列表、当前会话、主题、权限模式和加载状态。
- `chat` store：消息、处理状态、工具调用、权限请求、WebSocket 状态、轮次和工具统计。
- 现有 REST API：会话加载、创建、读取和删除。
- 现有 WebSocket：聊天发送、停止、模式切换和权限响应。

空状态示例需要在会话组件与输入组件之间增加一个前端草稿填充接口，但不改变发送协议。

## 异常与边界状态

- 无当前会话：输入区禁用并提示创建会话。
- 会话加载中：侧栏显示轻量骨架或加载状态。
- 会话详情加载失败：消息区显示可理解的失败提示，并保留重新选择会话的能力。
- WebSocket 连接中：顶栏显示连接中状态，避免仅使用顶部色条。
- WebSocket 断开：顶栏明确标记，发送按钮不可表现为可用状态。
- 工具失败：工具条使用失败图标与摘要，并允许展开查看参数。
- 长消息和长代码：限制内容宽度，代码区域横向滚动，不让页面整体溢出。

## 可访问性

- 所有按钮提供可见焦点状态和准确的 `aria-label`。
- 连接与工具状态不只依赖颜色。
- 正文与背景达到清晰的浅色模式对比度。
- 可点击元素使用明确的 hover、active 和 focus 反馈。
- 尊重 `prefers-reduced-motion`。

## 验证标准

### 自动验证

- `npm run check` 通过。
- `npm run build` 通过。
- 与本次组件交互相关的新增测试通过。

### 浏览器验证

在 1280px、1440px 和 1920px 桌面宽度检查：

- 无会话与空消息状态
- 新建和切换会话
- 普通用户/助手消息及长 Markdown
- 代码块与复制按钮
- 工具运行、成功、失败及展开状态
- 探索/完整模式切换
- 连接中、已连接和断开状态
- 权限确认弹窗
- 处理中停止操作
- 键盘焦点与减少动态效果

## 非目标

- 不新增移动端专用导航。
- 不新增总览、知识库、GitHub 分析或进度复盘页面。
- 不新增后端字段、学习计划模型或虚构统计数据。
- 不实现当前后端不支持的“60 秒免确认”。
- 不进行与会话体验无关的架构重构。
